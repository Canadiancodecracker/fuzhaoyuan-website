# 福兆源枸杞世家 官网

宁夏福兆源农业科技有限公司品牌官网。纯静态页面（HTML/CSS/JS），无构建步骤，支持中英文切换。

- `index.html` — 单页站点
- `assets/` — 图片资源

本地预览：`python3 -m http.server 8000`，打开 http://localhost:8000

## 图片目录
- `assets/products/` — 产品与礼盒图（来自企业简介文档，已压缩）
- `assets/gallery/` — 基地、门店、荣誉与证书图
- `assets/berries/`、`assets/field-berries/` — 首屏与关于我们的枸杞摆动精灵图
